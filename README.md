# cmd-share

局域网文件互传：**电脑跑起来，终端显示二维码，手机扫码即用**——安卓端零安装，
浏览器就是客户端。Rust + axum 实现，单文件 exe（约 2.3MB）。

## 用法

```cmd
cmd-share.exe                     :: 共享当前目录，随机配对码
cmd-share.exe D:\电影             :: 共享指定目录
cmd-share.exe --port 9000         :: 自定义端口（默认 8787）
cmd-share.exe --token abc123      :: 固定配对码
cmd-share.exe --ip 192.168.1.5    :: 手动指定本机 IP（自动探测失败时）
```

启动后终端直接显示地址和二维码，手机相机/微信扫一扫，或浏览器输入地址：

- **下载**：浏览电脑共享目录，点文件即下载
- **上传**：选文件或拖拽，多文件并行，带进度条；自动防重名 `(1)`、文件名清洗
- **文本互传**：手机发文本 → 自动进入电脑剪贴板；电脑剪贴板 → 手机端每 5 秒
  自动刷新，一键复制

## 安全模型

- 每次启动生成 6 位十六进制配对码，拼在 URL 里；**所有 API 无配对码一律 401**
- 下载接口只允许单段文件名，路径穿越（`../`、反斜杠、子目录）全部拒绝
- 上传文件名清洗：去路径、替换 Windows 非法字符、防保留名（CON/NUL…）、防重名
- 明文 HTTP——仅适合家庭/可信局域网，不要在公共 Wi-Fi 使用（HTTPS 在路线图）

## Windows 防火墙

首次运行可能弹出防火墙授权窗口，点"允许访问"即可（只监听局域网，不暴露公网）。

## 架构

```
src/
├── util.rs    文件名清洗/重名/路径安全（纯函数，重点单测）
├── net.rs     局域网 IP 探测（UDP connect 路由选择，不发包）
├── qr.rs      URL → 终端二维码（半块字符画 + 反色）
├── server.rs  axum 路由：token 中间件 / 列表 / 流式下载 / multipart 上传 / 双向文本
└── page.html  手机端单文件页面（原生 JS，无外部资源）
```

设计要点：下载用流式 `ReaderStream`（大文件不占内存）；上传流式写盘（上限 10GB）；
页面单文件内嵌进二进制（`include_str!`），零静态资源依赖。

## 已知边界

- 无断点续传、无目录上传、无 HTTPS、无 mDNS 自动发现（扫码即用所以不需要）
- 电脑剪贴板轮询是明文拉取，同网段知道配对码的人都能读——配对码即钥匙
